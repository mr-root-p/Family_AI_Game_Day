# يوم الألعاب العائلي بالذكاء الاصطناعي — Family AI Game Day

## التشغيل (Node.js 18+ — بدون npm install)
1. دبل كلك على `start.bat` — أو في Terminal داخل المجلد: `node server.js`
2. التطبيق: **http://localhost:3000** — شاشة النتائج المباشرة: **http://localhost:3000/scoreboard** (تلفزيون أو جوال على نفس الواي فاي، الرابط يطلع في الـ Terminal).
3. لازم **إنترنت** (موديلات الذكاء الاصطناعي تتحمّل من Google/jsDelivr أول مرة) و**Chrome أو Edge**.
4. اسمح للكاميرا والمايك لما يطلب المتصفح.

## الألعاب (كرة القدم + لعبتين أصليتين = مسار Cycle 3)
| اللعبة | نوعها | الذكاء الاصطناعي |
|---|---|---|
| ⚽ كرة القدم | فرق | MediaPipe Object Detector: يكشف اللاعبين والكرة، الفريق من لون التيشيرت، الهدف لما الكرة تدخل منطقة المرمى، الاستحواذ = أقرب لاعب للكرة، MVP = أكثر لاعب استحواذ |
| 🗣️ سلسلة الكلمات | فرق | التعرف على الكلام العربي (ar-AE): يتحقق من الحرف الأول والتكرار والوقت |
| 📸 البحث بالصور | فردي | كشف الأشياء + تحليل الألوان في الصور |

## الخطوات الست
١ اختر لعبة ← ٢ اللاعبين والفرق ← ٣ القوانين (نقاط/وقت/كسر تعادل) والكل جاهز ← ٤ الجولة (الدور، التحدي، المؤقت، النتيجة) ← ٥ نتائج الحكم (اللحظة + السبب + صورة) و"اعتماد نتائج الذكاء الاصطناعي" ← ٦ النتيجة النهائية + حقائق المباراة + MVP + لعبة ثانية.

## نصايح للديمو
- **كرة القدم:** صوّر من زاوية جانبية ثابتة، والفريقين بألوان مختلفة، والكرة واضحة (مب صغيرة جدًا). بعد رفع الفيديو: اختار لون كل فريق بالضغط على تيشيرت لاعب، وارسم المرميين.
- **سلسلة الكلمات:** في خانة "تجربة بدون مايك" تقدر تكتب الكلمة إذا المايك فيه مشكلة.
- صوّروا الشاشة وهي تبين: اللعب الحقيقي ← المربعات والنقاط اللي يكتشفها الذكاء الاصطناعي ← "نتائج الحكم" ← تحديث النتيجة.

## هيكل المشروع
```
server.js               سيرفر Node.js (بدون مكتبات خارجية)
public/index.html       التطبيق + الحكم الذكي (MediaPipe في المتصفح)
public/scoreboard.html  شاشة النتائج المباشرة (Server-Sent Events)
data/matches.json       المباريات المحفوظة (ينشأ تلقائيًا)
```

## مميزات السيرفر
- 🔐 **توقيع تقارير الحكم:** كل نتيجة من الذكاء الاصطناعي تنوقّع في `/api/sign` بـ HMAC-SHA256، وقبل الاعتماد التطبيق يتحقق عبر `/api/verify`. إذا أحد غيّر النقاط، التقرير يترفض.
- ⬇ تحميل تقرير الحكم الموقّع كملف JSON.
- 📺 شاشة نتائج مباشرة تتحدث لحظيًا (`/events`).
- 🏆 حفظ كل مباراة + لوحة صدارة العائلة (`/api/leaderboard`).
- تغيير المفتاح السري: `set JUDGE_SECRET=xxxx` قبل التشغيل.
